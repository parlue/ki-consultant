KI-Modell

Ollama muss auf diesem Rechner laufen. Wähle ein bereits lokal installiertes Modell. Der tägliche Lauf muss ebenfalls auf diesem Rechner erfolgen; GitHub Actions erreicht deinen lokalen Ollama-Dienst nicht.

Liest nur die Modellliste; erzeugt keine Texte.

Nachrichtenquellen

Nur ausgewählte Quellen werden beim nächsten Lauf abgerufen.

Umfang des Modellaufrufs

Das Modell wählt daraus bis zu acht Meldungen. Für Ollama ist der Eingabetext auf 30.000 Zeichen begrenzt (Beiträge × Zeichen); beim Wechsel werden zunächst 12 × 1.800 gesetzt. Ein Kontext von 32.768 Tokens wird angefordert; dafür muss genügend Arbeitsspeicher verfügbar sein.

Gespeichert wird ki-news/settings.json auf diesem Rechner. Für GitHub Actions muss diese Datei anschließend ins Repository übernommen werden. API-Schlüssel werden hier nicht abgefragt oder gespeichert: DeepSeek → DEEPSEEK_API_KEY, Claude → ANTHROPIC_API_KEY, OpenAI → OPENAI_API_KEY. Lokal als Umgebungsvariable des gestarteten Programms, auf GitHub als Repository-Secret.
