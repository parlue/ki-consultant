# Manuelle Probeausgabe

Die bearbeitbaren Inhalte liegen in `2026-10-21.json`. Sie sind bewusst kein Eintrag im automatischen Tagesarchiv: Unterschiedliche Veröffentlichungsdaten dienen der Inhalts- und Designabstimmung und dürfen nicht als vollständiges 24-Stunden-Briefing erscheinen.

Vorschau neu erstellen: `python scripts/build_news_preview.py` vom Repository-Hauptverzeichnis aus. Danach `ki-news/vorschau.html` direkt im Browser öffnen. Die erzeugte Datei enthält CSS, Inhalte und Suchlogik vollständig und funktioniert ohne Server oder API-Schlüssel.
